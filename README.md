Password Complexity Checker
This tool evaluates the strength of a password based on a set of criteria. It provides feedback to help improve weak passwords.

Features
Length Check: Ensures the password is at least 8 characters long.
Uppercase and Lowercase Letters: Checks for the presence of both uppercase and lowercase letters.
Numbers: Verifies if the password includes at least one numeric digit.
Special Characters: Ensures the password has at least one special character (e.g., @, #, $, !, etc.).
Feedback: Offers suggestions to improve weak or moderate passwords.
